## Purpose

Answer one question: **"What does the full leadership team think about this?"**

Executive Council presents FLOW's 6 AI domain executives — Engineering COO, Operations COO, Sales COO, HR COO, Security COO, Finance COO — each analyzing their domain and producing a synthesized organizational answer. Its primary action is asking the Council a strategic question and reviewing the debate.

---

## Target User

**Primary:** CTO, CEO/Executive  
**Secondary:** Head of Product, VP Engineering  
**Frequency:** Weekly strategic review; when facing a cross-functional decision

## Health Dashboard

Six cards in a 3×2 grid. Each card is generated by `executiveDashboard.healthReport()` — cached ~10 minutes, built from `healthReport()` per agent (lighter than full `analyze()`).

**Agent Health Card layout:**

```
┌──────────────────────────────────────────────┐
│  [agent icon]  Engineering COO               │
│  [status dot]  Nominal / Warning / Critical  │
│  ─────────────────────────────────────────   │
│  Top finding: "2 PRs blocking release"       │
│  Top risk:    "Deployment risk HIGH"         │
│  ─────────────────────────────────────────   │
│  [Ask Engineering COO →]                    │
└──────────────────────────────────────────────┘
```

Status dot colors:
- Nominal: `var(--status-healthy)`
- Warning: `var(--status-warning)`
- Critical: `var(--status-critical)`

Card border: 1px `var(--border)`. On Warning: left border 2px `var(--status-warning)`. On Critical: left border 2px `var(--status-critical)`.

`[Ask Engineering COO →]` pre-fills the AskCouncilInput with `"Engineering COO: "` prefix to route to that specific agent.

```

│  Ask the Council anything about your company...               │
│                                                               │
│                                              [Ask Council →]  │

- Multi-line textarea, min-height 56px, expands on focus
- Placeholder rotates every 4s:
  - `"Should we postpone Release 2.5?"`
  - `"What's the biggest risk to this quarter?"`
  - `"Is the team healthy enough to hire now?"`
  - `"What should I focus on this week?"`
- Submit: `Enter` (single line) or `⌘Enter` (multi-line), or button click
- On submit → enters loading state (see below)

## Analysis Loading State

After the question is submitted, while the 6 agents analyze in parallel:

```
Asking the Council...

[Engineering COO]  ████████ Analyzing...
[Operations COO]   ████████ Analyzing...
[Sales COO]        ████████ Analyzing...
[HR COO]           ████████ Analyzing...
[Security COO]     ████████ Analyzing...
[Finance COO]      ████████ Analyzing...
```

- Each agent bar updates to `✓ Ready` as it completes (agents respond at different speeds)
- `⌘.` cancels the request at any time
- Agents that time out (>60s) show: `[Engineering COO] Timed out — partial response available`
- The synthesis begins once ≥ 3 agents have responded (does not wait for all 6 if some time out)

## Debate Panel

After analysis completes, three sections render:

### 1. Agent Response Cards

Side-by-side (2 per row, 3 rows for 6 agents). Each card:

```
┌───────────────────────────────────┐
│  [Engineering COO]  [confidence]  │
│  ──────────────────────────────   │
│  Finding: [1–2 sentences]         │
│  ──────────────────────────────   │
│  Recommendation: [1 sentence]     │
│  ──────────────────────────────   │
│  ▶ Evidence (collapsed)           │
└───────────────────────────────────┘
```

Confidence shown as a verbal label (not a percentage):
- High evidence → `"Strong signal"`
- Medium evidence → `"Moderate signal"`
- Low evidence → `"Limited data"`

Never show raw confidence numbers.

### 2. Debate Summary

Appears when ≥ 2 agents disagree:

```
DEBATE

Engineering COO and Operations COO disagree on timeline.
  Engineering: "Postpone — deployments are risky this week."
  Operations: "Ship — delay creates more process debt."

Security COO has a veto position:
  "Do not ship until the authentication vulnerability is patched."
  [Security veto takes precedence — see governance]
```

Disagreement detection: deterministic (polarity by finding signal count, confidence spread).  
Security COO defers position: if Security flags a risk, it is always surfaced prominently.

### 3. Synthesized Answer

```
COUNCIL POSITION

[2–4 paragraph synthesized answer]
[The Council recommends: [1-sentence directive]]

─────────────────────────────────────────────
MINORITY OPINION
[If any agent held a significantly different position:]
"HR COO: While the Council recommends proceeding, 
the HR perspective is that team bandwidth may not 
support this timeline."
─────────────────────────────────────────────
[Copy answer]  [Ask a follow-up]  [View full analysis]
```

Synthesis: via `BrainRouter.reason()` (Gemini + deterministic structured fallback).

[Engineering COO]   ████ Analyzing...

```

Response: single `AgentResponseCard` + no debate panel.

`GET /api/council/agent/{agentId}` endpoint.

## AI Behavior

**Full Council:** `POST /api/council/ask` → routes → 6 parallel `analyze()` → debate → synthesis.

**Single agent:** `GET /api/council/agent/{agentId}?question={q}`.

**Dashboard:** `GET /api/council/dashboard` — 6 `healthReport()` calls, cached 10 min.

**Performance:** Council is bounded by Brain call speed (~28–30s per agent). Agents answer as they complete — UI shows progressive updates. Users who understand this deliver better questions (specific domain context reduces retrieval time).

**Command Center:** Typing on this page auto-routes to the AskCouncilInput (not the global Brain).

## Error State

**All agents time out:**
```
"The Council was unable to complete analysis in time.
The workspace may need more connected sources.
[Try again]  [Ask a single agent instead]"
```

**Partial response (≥1 agent responds):**
- Timed-out agents show `"[Agent name] — Timed out"` card (greyed out)
- Synthesis proceeds with available responses
- Synthesis carries a notice: `"Note: [N] agent(s) did not respond in time. This analysis is based on [N] of 6 domains."`

## Previous Questions (History)

Below the AskCouncilInput (when a previous answer exists):

```
PREVIOUS QUESTION
"Should we postpone Release 2.5?"
Asked 2 hours ago · 5 of 6 agents responded

[View answer]  [Ask follow-up]
```

History is session-only (not persisted to DB in v1). `[Ask follow-up]` re-opens the DebatePanel and submits the follow-up in context.
